# Stock Portfolio Tracker

## Introduction

Stock Portfolio Tracker is a Python-based application
that calculates the total investment value of stocks.

## Features

- Predefined stock prices
- User stock selection
- Quantity input
- Automatic investment calculation
- Portfolio summary
- Text file report generation

## Technologies Used

- Python
- Dictionaries
- Lists
- Loops
- Conditional Statements
- File Handling

## How to Run

1. Install Python.
2. Download the project.
3. Open the folder in VS Code.
4. Run:

python stock_tracker.py
